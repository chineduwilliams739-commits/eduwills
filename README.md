# EDUWILLS

**Learn. Practice. Excel.**

EDUWILLS is an AI-powered learning and quiz platform designed for Nigerian learners.

## Phase 1 — Book Learner

The first release focuses on the Book Learner experience. Learners will be able to search for books, identify authors, generate AI-powered quizzes, and review their quiz history.

### Initial learner areas

- **QUIZ** — search for a book and generate a quiz
- **HISTORY** — review previous quiz attempts and scores
- **ACTIVATION** — manage learner activation
- **PERSONAL** — profile and account settings

### Future learning categories

- Senior Secondary — WAEC, JAMB, NECO and Normal Test — ₦3,000
- Junior Secondary — BECE, NECO and Normal Test — ₦3,000
- Primary — ₦2,000
- Book Learner — ₦4,000

Only Book Learner is being opened in Phase 1; the other categories are intentionally locked in the interface.

## Tech stack

- Next.js 14 App Router
- React 18
- TypeScript
- Tailwind CSS
- Lucide icons

## Development

Install dependencies and run the development server with:

```bash
npm install
npm run dev
```

The AI, authentication, phone verification, payments, persistent book library, and production database will be connected in subsequent implementation phases.
